# 10.13.25-safe.1 实验性测试包：运行前必读

适用于 Windows x64。内含 .NET 8 运行时，不需要另装 .NET；仍需 Microsoft Edge WebView2 Runtime。主程序未进行代码签名，启动按原项目要求请求管理员权限；请核对发布来源及 SHA-256，不要为运行它关闭系统安全功能。

## 首次部署

1. 保存工作，结束游戏并退出 MSI Afterburner、其他硬件调参工具。先从托盘完全退出旧版蛟龙控制中心，否则单实例检查会阻止新版启动。
2. 将整个 ZIP 解压到一个新的、可写目录。不要只复制 EXE；不要覆盖旧版目录，也不要复制旧版 `config/` 或开启开机自动应用。
3. 启动 `JiaoLongControl.exe`。先检查页面显示和只读检测。这个发布包不附带个人配置，不自动写入实验性 GPU 曲线。
4. GPU 页面先“读取曲线”再预览。暂时不要同时修改 CPU CO、功耗和 GPU 曲线，避免无法定位不稳定原因。没有适用于所有 4060 Laptop 的通用稳定参数。

## CPU 与 PawnIO

CPU 基本设置使用 OEM / Windows 接口，兼容性取决于机型；SMU / CO 仍然需要 PawnIO 内核驱动。内置官方签名安装器的文件/产品版本是 **2.2.0.0**，并非 3.1.0。已安装时先查看状态，不必重复安装。只有在设置页明确确认后才打开交互式安装器；请选择官方签名版，不选 Unrestricted。此包不会替你安装驱动。

## GPU 试用与恢复

- 曲线功能是实验性私有 NVAPI 路径，**未在 RTX 4060 Laptop 上执行真实写入验证**。读取失败或提示不支持时停止，不要绕过检查。
- 只有明确确认并点击“试用 60 秒”才尝试写入。成功读回后可确认保留本次会话；正常退出仍尝试恢复原偏移。备份位于 `%LOCALAPPDATA%/JiaoLongControl/curve-backup-v1.json`。
- 计时器不能保证在驱动挂起、黑屏、系统崩溃、强制结束进程时工作。再次打开程序时，保留备份并按页面提示恢复；驱动或设备变化时不会强套旧备份。
- 回到旧版前，先在新版恢复曲线并确认成功，再退出新版、打开旧版。仅换回旧 EXE 不等于恢复硬件。不要删除恢复备份来绕过应用门槛。
